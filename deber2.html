Tema: Autenticación con Email/Password y Google

Paso 1: Configurar el proyecto

Lo primero que hice fue entrar a la consola de Firebase y crear mi proyecto. Ahí mismo activé los "Sign-in methods" para poder usar el correo y la cuenta de Google.

Después, instalé la librería en mi proyecto con este comando:

npm install firebase

Paso 2: Conectar Firebase

Creé un archivo para guardar mis credenciales y conectar mi aplicación con el servicio de Firebase.

// Importo lo que necesito
import { initializeApp } from "firebase/app";
import { getAuth } from "firebase/auth";

// Configuración con mis llaves
const firebaseConfig = {
  apiKey: "MI_API_KEY",
  authDomain: "mi-app.firebaseapp.com",
  projectId: "mi-app-id"
};

const app = initializeApp(firebaseConfig);
export const auth = getAuth(app);

Paso 3: Login con correo y clave

Programé una función para que el usuario pueda entrar usando su email y contraseña. Usé un try/catch para que si hay un error (como una clave mal puesta), me avise.

import { signInWithEmailAndPassword } from "firebase/auth";

const ingresarConEmail = async (email, password) => {
  try {
    await signInWithEmailAndPassword(auth, email, password);
    console.log("¡Usuario logueado!");
  } catch (error) {
    alert("Error: " + error.message);
  }
};

Paso 4: Login con Google

Para Google es más fácil porque solo uso un "Provider" y Firebase abre una ventanita para elegir la cuenta.

import { GoogleAuthProvider, signInWithPopup } from "firebase/auth";

const loginGoogle = () => {
  const provider = new GoogleAuthProvider();
  signInWithPopup(auth, provider)
    .then((result) => {
      console.log("Hola " + result.user.displayName);
    });
};

Paso 5: Revisar si el usuario está activo

Puse un "escuchador" para que mi app sepa si hay alguien logueado. Si no hay nadie, puedo redirigirlo al login automáticamente.

auth.onAuthStateChanged((user) => {
  if (user) {
    console.log("El usuario sigue aquí");
  } else {
    console.log("Sesión cerrada");
  }
});

Paso 6: Cerrar sesión

Por último, hice la función para salir. Es sencillo, solo llamo a signOut y Firebase limpia todo.

import { signOut } from "firebase/auth";

const salir = () => {
  signOut(auth).then(() => {
    console.log("Sesión finalizada");
  });
};
