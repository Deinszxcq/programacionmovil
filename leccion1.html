Lección 1: Programación Orientada a Objetos

Clases, objetos, herencia, polimorfismo y clases abstractas — explicado claro y con ejemplos prácticos.

¿Qué es POO y por qué te conviene?

La Programación Orientada a Objetos (POO) es una forma de programar donde organizas tu código como si fueran “cosas del mundo real”: usuarios, productos, autos, cuentas, etc.

  • Clase = el “molde” (la plantilla).
  • Objeto = una “copia real” creada desde ese molde.
  • Te ayuda a hacer código más ordenado, reutilizable y fácil de mantener.
Ejemplo rápido: La clase Auto define cómo son los autos. Un objeto es miAuto con color rojo y placa X.

1) Clases y Objetos

Aprende a crear “moldes” (clases) y a fabricar “cosas reales” (objetos).

¿Qué es una clase?

Una clase es una plantilla con: atributos (datos) y métodos (acciones).

MOLDE ATRIBUTOS MÉTODOS
Atributo: nombre, edad, saldo.
Método: saludar(), depositar(), pagar().

Ejemplo práctico (Java)

Clase Persona y creación de objetos:

// 1) CLASE (molde)
class Persona {
  String nombre;
  int edad;

  void saludar() {
    System.out.println("Hola, soy " + nombre + " y tengo " + edad + " años");
  }
}

// 2) OBJETOS (copias reales)
public class Main {
  public static void main(String[] args) {
    Persona p1 = new Persona();
    p1.nombre = "Ana";
    p1.edad = 20;
    p1.saludar();

    Persona p2 = new Persona();
    p2.nombre = "Luis";
    p2.edad = 22;
    p2.saludar();
  }
}
Idea: la clase define “cómo es una Persona”; p1 y p2 son personas reales con valores diferentes.

2) Herencia

Reutiliza código: una clase “hija” hereda atributos y métodos de una clase “padre”.

¿Qué es herencia?

Si varias clases comparten cosas, creas una clase base y las demás heredan. Evita repetir código.

REUTILIZAR PADRE → HIJO
Ejemplo: Animal (nombre, comer()) → Perro y Gato.

Ejemplo práctico (Java)

Una clase padre Animal y una hija Perro:

// CLASE PADRE
class Animal {
  String nombre;

  void comer() {
    System.out.println(nombre + " está comiendo");
  }
}

// CLASE HIJA (hereda de Animal)
class Perro extends Animal {
  void ladrar() {
    System.out.println(nombre + " dice: ¡Guau!");
  }
}

public class Main {
  public static void main(String[] args) {
    Perro dog = new Perro();
    dog.nombre = "Rocky";

    dog.comer();   // heredado de Animal
    dog.ladrar();  // propio de Perro
  }
}
Perro no “re-escribe” comer(); lo hereda. Y además agrega ladrar().

3) Polimorfismo

Misma acción, diferentes resultados según el objeto real que tengas.

¿Qué es polimorfismo?

Significa “muchas formas”: un método puede comportarse diferente dependiendo de la clase hija. Normalmente se logra con sobrescritura (override).

MISMO MÉTODO DIFERENTE SALIDA
Ejemplo: hacerSonido() existe en Animal, pero Perro lo hace “guau” y Gato “miau”.

Ejemplo práctico (Java)

Una referencia Animal que puede ser Perro o Gato:

class Animal {
  void hacerSonido() {
    System.out.println("Sonido genérico");
  }
}

class Perro extends Animal {
  @Override
  void hacerSonido() {
    System.out.println("Guau guau");
  }
}

class Gato extends Animal {
  @Override
  void hacerSonido() {
    System.out.println("Miau");
  }
}

public class Main {
  public static void main(String[] args) {
    Animal a1 = new Perro(); // referencia tipo Animal, objeto real Perro
    Animal a2 = new Gato();  // referencia tipo Animal, objeto real Gato

    a1.hacerSonido(); // imprime "Guau guau"
    a2.hacerSonido(); // imprime "Miau"
  }
}
Lo importante: mismo método (hacerSonido) pero el resultado depende del objeto real.

4) Clases Abstractas

Sirven como base: no se pueden instanciar, y obligan a las hijas a implementar métodos.

¿Qué es una clase abstracta?

Es una clase “incompleta” que se usa como plantilla avanzada. No puedes crear objetos directamente de ella.

BASE NO INSTANCIAR OBLIGA IMPLEMENTAR
Si una clase tiene un método abstracto, las clases hijas deben implementarlo sí o sí.

Ejemplo práctico (Java)

Figura base con método obligatorio:

abstract class Figura {
  abstract double area();

  void mostrarTipo() {
    System.out.println("Soy una figura");
  }
}

class Cuadrado extends Figura {
  double lado;

  Cuadrado(double lado) {
    this.lado = lado;
  }

  @Override
  double area() {
    return lado * lado;
  }
}

public class Main {
  public static void main(String[] args) {
    // Figura f = new Figura(); // ❌ ERROR: no se puede instanciar abstracta

    Figura c = new Cuadrado(5);
    c.mostrarTipo();
    System.out.println(c.area()); // 25
  }
}
Figura define reglas (area()) y las hijas (Cuadrado) cumplen.
